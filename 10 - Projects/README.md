# 10 - Projects

One note per active program or initiative. A **Project** has a defined outcome and a natural end state. When complete or deprioritized, move it to `40 - Archives` rather than deleting it.

Create new ones from `90 - Templates/Project Note.md` — the `note-creation` skill does this for you and keeps the frontmatter/structure exact.

**Used by:** `note-creation`, `note-update`, `daily-update`, `weekly-review`, `knowledge-retrieval`, `autoresearch` (all read or write here). This is core to the kit — don't delete it.

Full conventions and the project note structure: [README.md](../README.md#10---projects).
