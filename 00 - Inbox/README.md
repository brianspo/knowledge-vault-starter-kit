# 00 - Inbox

Landing zone for quick capture and AI-proposed vault updates.

- **`Vault Updates YYYY-MM-DD.md`** — staged change proposals written by the `daily-update` skill after reviewing meeting notes. Review, edit inline, then say "apply today's vault updates" before anything lands in a real note.
- Anything else you drop here temporarily, not yet filed elsewhere.

**Process cadence:** clear weekly. Nothing here is permanent.

**Used by:** `daily-update`. If you're not running that skill, this folder just sits empty — harmless to keep.

Full conventions: [README.md](../README.md#00---inbox).
