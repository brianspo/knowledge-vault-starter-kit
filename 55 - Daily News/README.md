# 55 - Daily News

Daily news briefs produced by the `news-brief` skill. Filename: `YYYY-MM-DD - News Brief.md`.

Each brief is a checklist — check off what you read, tag `#useful` on anything worth keeping. That feedback loop is what tunes `skills/news-brief/references/topics.md` over time, so the briefs get more relevant the longer you run it.

**Used by:** `news-brief` only. Delete this folder if you're not installing that skill.
