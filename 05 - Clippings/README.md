# 05 - Clippings

Raw capture of a web page or external content — a browser clip, a pasted article, anything not yet distilled into a proper `30 - Resources` entry or a `35 - Techniques` note.

Treat this as a lower-confidence holding pen, not a system of record. If something here turns out to matter, promote it (move + reformat) rather than leaving it to accumulate indefinitely.

**Used by:** nothing in this kit writes here automatically — it's a manual-capture folder. Delete it if you don't do web clipping, or if you'd rather drop raw captures straight into `30 - Resources`.
