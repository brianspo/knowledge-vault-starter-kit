# 70 - Weekly Reviews

Cadenced weekly reflection notes. Filename: `YYYY-WWW.md` (ISO week numbering, e.g. `2026-W34.md`).

Drafted by the `weekly-review` skill, typically Friday mornings — it pre-fills what the week's meeting notes and project statuses support, and leaves the personal-reflection sections (What I Learned, Personal Pulse, program-status emoji) blank on purpose, since only you can fill those in.

**Used by:** `weekly-review`, `accomplishments-reflection` (reads these as its highest-signal source). Delete this folder only if you're skipping both of those skills.
