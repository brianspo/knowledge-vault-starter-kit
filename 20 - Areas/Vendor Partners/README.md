# 20 - Areas / Vendor Partners

One note per vendor relationship worth running context on — contract terms, account team, current engagements, open items. Create new ones from `90 - Templates/Area Note - Vendor Partner.md`.

**Used by:** `note-creation`, `note-update`, `client-brief` (if you installed it — pulls vendor history before a call), `negotiation` (if installed — same reason).

Delete this folder if you don't deal with vendors directly, or if that's tracked somewhere else already (a real CRM, a procurement system).
