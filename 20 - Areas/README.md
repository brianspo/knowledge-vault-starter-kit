# 20 - Areas

Ongoing responsibilities with no end date — the people and relationships you track running context on, not discrete projects.

- **`Direct Reports/`** — one note per person who reports to you.
- **`Vendor Partners/`** — key vendors/suppliers worth running context on (contract terms, account team, open items).
- **`Key Contacts/`** — external or cross-org contacts worth running context on, without a vendor relationship.
- **`Professional/`** — your own career artifacts: an accomplishments log, a resume seed. Not about anyone else.

Each subfolder has its own README with the note structure and which skill populates it. Delete any subfolder you don't need — e.g. if you don't manage vendors directly, drop `Vendor Partners/`.

Full conventions: [README.md](../README.md#20---areas).
