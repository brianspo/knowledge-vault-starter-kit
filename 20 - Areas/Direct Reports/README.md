# 20 - Areas / Direct Reports

One note per person who reports to you. Create new ones from `90 - Templates/Area Note - Direct Report.md`.

**Note structure:** Role & Scope, Current Focus Areas, Running Context (dated bullets, add-only), What They Need From Me, Open Commitments I've Made to Them (checkboxes — these feed the Dashboard's live commitments table).

**Used by:** `note-creation`, `note-update`, `daily-update` (running context + commitments), `weekly-review`. Delete this folder only if you have no direct reports to track — most leaders will keep it.
