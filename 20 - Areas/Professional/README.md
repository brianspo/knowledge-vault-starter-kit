# 20 - Areas / Professional

Your own career artifacts. Not about anyone else, not about a project.

- **`Accomplishments Log.md`** — running record of what you've led, decided, and delivered. Built and maintained by the `accomplishments-reflection` skill; created automatically on its first run if it doesn't exist yet.
- **`Resume Seed.md`** — optional. If present when `accomplishments-reflection` runs for the first time, prior accomplishments get imported as a baseline (flagged `(seeded from resume)` so you know which entries haven't been through a real reflection session).

**Used by:** `accomplishments-reflection` only. Delete this folder if you don't plan to run that skill.
