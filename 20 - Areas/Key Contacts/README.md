# 20 - Areas / Key Contacts

One note per external or cross-org contact worth running context on — not a vendor, not a direct report, but someone whose relationship you want to remember (a peer leader, a governing-body contact, a recurring collaborator). Create new ones from `90 - Templates/Area Note - Key Contact.md`.

**Used by:** `note-creation`, `note-update`, `client-brief` (if you installed it — checks here before a meeting).

Delete this folder if you don't have this category of relationship, or fold it into `Vendor Partners/` if the distinction doesn't matter to you.
